# 🚀 Selected Work

## 📊 Retail Sales Performance Dashboard — Excel
**Problem:** A raw 50+ record sales dataset with inconsistent date formats, mixed casing, misspelled cities, and negative quantities — unusable for reporting.

**What I did:**
- Built a cleaning layer to standardize dates, city names, customer names, payment methods, and order statuses
- Created calculated fields for **Total Sales** and **Total Amount**
- Modeled the data with **PivotTables** across category, city, payment method, and order status
- Designed an executive **KPI dashboard**: Total Orders, Total Sales, Units Sold, Completed Orders, Average Order Value

**Outcome:** Identified **Electronics** as the top revenue category and **Pune** as the top-performing city, giving a clear picture of where revenue concentration and operational risk (cancellations/returns) sit.

`Excel` `PivotTables` `Data Cleaning` `KPI Design` `Dashboard Development`

## 🏦 Loan Approval Prediction System
**Problem:** Manual loan screening is slow and inconsistent.

**What I did:**

- Trained and compared **Logistic Regression** and **Decision Tree** classifiers
- Evaluated with accuracy score, confusion matrix, and classification report

**Outcome:** A reproducible model pipeline that demonstrates how classification can support faster, more consistent screening decisions.

`Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib`

## ⚖️ Justice Bot — RAG-Based Legal Advisor
**Problem:** General-purpose LLMs hallucinate on domain-specific questions.

**What I did:**
- Built a **Retrieval-Augmented Generation** pipeline with **LangChain**
- Indexed domain documents in **FAISS** for semantic retrieval
- Grounded LLM responses in retrieved context instead of model memory
- Tuned chunking, retrieval depth, and prompt structure for answer relevance

**Outcome:** Context-aware responses with traceable source grounding — a pattern directly transferable to internal knowledge-base and document-QA use cases in any business.

`Python` `LangChain` `FAISS` `LLMs` `RAG`
